# Biwenger MCP 0.2.2 — beta privada

Corrige el descubrimiento de ligas según la estructura real de Biwenger. Una liga normal se identifica como `mode: league` y `type: normal`; la opción de fichajes Clásica se encuentra en `marketMode: classic`.

El asistente admite las ligas de LaLiga Clásica que utilicen cualquiera de los siete sistemas de puntuación predefinidos: Diario AS, SofaScore, Estadísticas, Feeberse Score, Media AS y SofaScore, Media AS y Feeberse o Biwenger Social. Las puntuaciones personalizadas siguen pendientes de validación.

La instalación del MCPB, el login, el descubrimiento de tres ligas, la selección de una liga SofaScore y las consultas privadas se validaron con Claude Desktop en macOS.
