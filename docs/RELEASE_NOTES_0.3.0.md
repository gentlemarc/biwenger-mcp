# Biwenger MCP 0.3.0 — beta privada

Rediseña por completo el asistente local de conexión con una identidad visual propia inspirada en el entorno deportivo, sin copiar la composición, los logotipos ni los recursos de Biwenger.

- Aviso visible de proyecto no oficial y de capacidades exclusivamente de lectura.
- Lenguaje neutral para cualquier ordenador y almacenamiento seguro del sistema.
- Estados diferenciados para acceso, selección de liga, conexión completada y desconexión.
- Instrucciones claras para reiniciar Claude Desktop después de cambiar la sesión.
- Enlace a la ayuda oficial para cuentas creadas con Google, Apple o Facebook, sin mostrar botones sociales no funcionales.
- HTML, CSS y JavaScript autocontenidos, sin fuentes, imágenes ni scripts remotos.
- Conserva loopback, nonce, caducidad, límites de entrada, CSP y ausencia de registros de credenciales.
